The Archive of Rooms

A long hallway of closed doors. Each door is a DSM-5 diagnosis, tagged with its ICD-10-CM code. Walk slowly.

Rooms follow the DSM-5 chapter order and codes are ICD-10-CM. Where a diagnosis has several codes (by severity, subtype or specifier), the code family is shown with an x, so check the official code set for the exact one. Summaries are short, original plain-language descriptions. This is not the DSM-5 text, it does not contain diagnostic criteria, and it cannot diagnose anyone. For the full manual, use the APA’s publication. If you’re struggling, a licensed clinician is the right door to knock on. Import accepts a JSON array of objects with room, name, code and summary, so you can load your own licensed data.
